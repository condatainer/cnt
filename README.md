# CNT - CondaTainer default recipe sources

The default recipe collection for [CondaTainer](https://github.com/condatainer/condatainer). A recipe is one file that builds an overlay.

```
source.json     what this collection is
index/          generated by CI
recipes/        one file per module
helpers/        launchers for interactive services
scripts/        index generators
```

To write or change a recipe, see [CONTRIBUTING.md](CONTRIBUTING.md).

```yaml
sources:
  - cnt: https://raw.githubusercontent.com/condatainer/recipe/main
```
